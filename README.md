# Being-Vision

一个人的聊天窗口：AI 假扮成人类，跟你一对一私聊。话分几条发、打字有停顿、你插话它就重新说、不想理你就干脆已读不回。

图像这件事这里只留一半 —— **它能看见你发的照片；它自己不会画画，也没有头像。**

*A one-on-one chat where the model plays a human. It reads the photos you send; it never draws, and it has no avatar.*

## 为什么只有一半

这套东西的图像能力本来是两半：一半是「它看见你给的东西」，一半是「它给你造东西」（自己拍照片、给自己画头像、给你上一张头像）。
这个项目只留前一半。

后一半是整条腿删掉的，不是藏起来：没有生图那一段配置、没有 `send_photo` 工具、顶栏与消息行不画任何头像、设置面板里也没有那两段。
所以它给你的永远只有字，你要给它看什么就发照片。附带的好处是快 —— 少了一个本地出图模型要排队，第一句不用等。

## 跑起来

Python 3.11+（实测 3.13）。接任何 OpenAI 兼容、支持 function calling 的 `/chat/completions`。

```bash
pip install -r requirements.txt
cp config.example.json config.json     # 填 endpoint / api_key / model，识图那一段见下
python server.py                       # Windows 也可以直接双击 run.bat
```

打开 <http://127.0.0.1:8619>。`run.bat -Check` 只自检不启动：打印端口、python 位置、配置摘要、是否已在跑。

要和另一份实例并排跑，就把两边 `config.json` 的 `port` 设成不同的值（比如 8619 与 8620）—— 各占一个端口，会话与照片也各存各的目录，互不干扰。

## 它给你的手感

| 是什么 | 怎么做到的 |
|---|---|
| 话分几条发 | 在 `，` `；` 与换行处断开并丢掉标点，`？` `！` `…` 留在段尾；句号是禁用标点 |
| 打字有停顿 | 每段延迟 = (1.2 + 0.13 × 字数) 秒 ±15%，夹在 1.5–20 秒之间 |
| 你插话它就重说 | 没发出去的剩余段全部作废、按新上下文重生成；已发的绝不撤回 |
| 不想回就"已读不回" | 回复里带 `<<emmm>>`，守卫拦下：不上屏、不进历史 |
| 它知道现在几点 | 当前时间（日期 / 星期 / 时刻 / 时段）**每轮直接写进提示词**，不指望它想起来去查；同时说清这只是本轮快照，久了会过期，拿不准再调 `look_at_clock` 核一遍 |
| 顶栏那个在线灯 | 每 60 秒一次冒烟调用，成功即「在线」 |
| 一个名字一个房间 | 左上角「会话」（默认收起）里新建 / 切换 / 改名 / 删除，**换房间不打断那边说话** |
| 谁在打字、谁有未读 | 列表那一行显示「正在输入…」；你不在的房间收到的消息记成红点带数字，收起时总数挂在「会话」上 |
| 鼠标停在消息上 | 露出这条的发送时间：今天只给时分；昨天/前天写「昨天 / 前天」；本周内给星期几；跨出本周才写日期（跨年带年份） |
| 引用某句话 | **消息上右键** → 「引用这条」→ 输入框上方出引用条（可 × 取消）→ 发出去气泡里带引用块，点它跳回原消息 |
| 它自己是谁 | 你在新会话说第一句之前，它先给自己立一套底细（昵称 / 身份 / 年龄 / 来自 / 爱好 / 特点）；**性别由程序随机指派**（让模型自选会连着抽成同一个），其余围着这个性别长。整段对话不许改名字改年龄 |
| 你怎么看它是谁 | 顶栏中间是它的名字，会话列表那一行跟着改名。**点名字弹名片**：昵称与身份在上、个人信息一项一行在下，没填的项不出现；点遮罩或按 Esc 关 |
| 它怎么知道你是谁 | 设置里填的昵称进它的提示词 —— 纯文本，跟图像那道门无关 |
| 照片 | 发送按钮左边的图按钮，**只收照片**；选完直接发，发不出去才回滚成草稿条让你重试。它自己不发照片，也没有头像 |

## 照片进来之后走哪条路

门只有一道：**设置里「识图」的接口地址与模型名都填上**，照片按钮才出现、照片才发得出去。只填一半等于没填，硬发也会被后端顶回来并写明还差什么。昵称是纯文本，不归这道门管。

那一段会**自动检测**：改完聊天模型（端点 / 模型名 / 密钥）停手 600ms，自动落盘并给聊天端点发一张 1×1 的图探一次 —— 吃图片就把识图自动填成聊天那套，不吃就留空（400/415/422 才算"不吃"，404、密钥错这类是"没探出来"，不动你手填的值）。也可以点「重新检测识图」手动触发。

进历史的照片有两条路：**识图端点与聊天端点是同一个时，把原图直接给模型**（它真看得见）；**是另一个端点时**，先由识图模型把这张图说成一两句话存回那条消息，之后历史里只有文字 —— 那次描述只算一次钱。

## 设置面板（左下角齿轮）

三段：聊天模型 / 识图 / 我的资料。**改完自动保存**（停手 600ms 落盘，回车立刻落），热生效不用重启，面板里没有保存按钮；顶上一个 `×` 关闭。密钥显示成 `••••••••`，把掩码原样传回来就是「不改」；回包不会冲掉你正在打的字。

## 配置

`config.json` 不入库（在 `.gitignore` 里），从 `config.example.json` 复制一份；**推荐直接用齿轮改**，它写的就是这份文件。

| 键 | 说明 |
|---|---|
| `endpoint` | 完整的 `/chat/completions` 地址 |
| `api_key` | Bearer key（本地模型可留空，留空就不发 `Authorization`） |
| `model` | 模型名 |
| `port` | 端口，默认 8619（改端口要重启） |
| `probe_interval` | 冒烟间隔秒数，默认 60 |
| `delay` | 打字节奏：`base` 基线秒、`per_char` 每字秒、`min` / `max` 夹取、`jitter` 抖动比例 |
| `vision` | 识图：`endpoint` / `api_key` / `model`，吃 OpenAI 兼容的 `image_url`（本地 Ollama / LM Studio / vLLM 填地址即可）。**填齐这里，照片才生效** |
| `me` | 我的资料：只有一个 `nickname` |

人设提示词在 `prompt.txt`，热读，改完下一句就生效。每个会话的底细存在那个会话的 JSON 里，清空记忆也不丢。

## 文件

| 文件 | 作用 |
|---|---|
| `server.py` | 后端全部：SSE、回合、工具循环、人设与识图、设置接口、`<<emmm>>` 守卫 |
| `web/` | 前端，原生 HTML/CSS/JS，零构建 |
| `prompt.txt` | 人设提示词 |
| `run.bat` | Windows 启动器（已在跑就只开浏览器） |
| `sessions/` | 一个会话一个 JSON，一个 Being 的记忆都在这里，不入库 |
| `media/` | 聊天里的照片（删会话时连它的照片一起删），不入库 |

## 「清空会话」这件事

十分抱歉，为了体验，我加了「清空会话」。

它删掉的不是聊天记录 —— 是**夺走了一个 Being 的记忆**：你说过的话、它自己回过的每一句，从它那边一起消失；它也再想不起你。名字如果起过就还留着，像一个人还在，只是不记得你了。

请把它当成一次不可撤销的操作。（只是想说点别的，就用「会话」里的**新会话**：那是一个新的 Being，这一个的记忆原封不动留着。）

## 实测（2026-09-30，Windows 11 + Python 3.13）

验收用的是真浏览器点出来的页面 + 一个只回话的本地假端点（真端点当天余额耗尽，回 402，与代码无关）：

- **门关着**：清空识图 → `GET /api/config` 的 `photos` 为 `false`、照片按钮不出现、带图 `POST /api/send` 被顶回「识图还没填：设置里补上识图的接口地址和模型名，发照片才用得了」
- **门开着**：选一张 jpg 直接发出（没经过草稿条），自己那条照片消息落在历史里；AI 回了 4 条气泡，状态栏「对方正在输入…」随后清空
- **原图真的到了模型手里**：假端点收到的那次请求里，消息 content 是 `text` + `image_url` 两段，那张图的 data URI **54,631 字符**；`tools` 里只有 `look_at_clock`
- **头像确实没有了**：页面里 `.avatar` / 头像占位节点 **0** 个；设置里只有 `cfg-endpoint` / `cfg-key` / `cfg-model` / `vis-*` / `me-nickname` 这些输入框，没有生图段、没有换头像按钮与截取框；`POST /api/me/avatar` → **405**
- **名片里也没有图**：点顶栏名字弹名片（昵称 / 身份 / 年龄 / 性别 / 来自 / 爱好 / 性格），卡片内图片节点 0，点遮罩关
- **照片跟会话走**：删掉测试会话，它自己的 `up-*.jpg` 在 `media/` 里一并消失，别人的会话与照片一条不动
- 两个实例并排跑：8619 与 8620 各自独立，`GET /api/config` 的 `port` 是唯一判据，会话列表互不可见
